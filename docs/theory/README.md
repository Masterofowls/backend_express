## How to use

1. Read the theory doc for your stage end-to-end.
2. Answer the **Self-check** questions (in chat or privately).
3. Open `stages/NN-*/LESSON.md` for checkpoints + practice tasks.
4. Code in `practice/` — tutor reviews; you write the code.
5. Run `checks/` when ready.

## Rule

Theory explains *why*. Practice proves *you can*. Solutions are last resort.
