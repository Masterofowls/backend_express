# Contributing (learner workflow)

1. Work only in `stages/NN-*/practice/` until checks pass.
2. Do not copy `solution/` until you have attempted practice.
3. Update `docs/PROGRESS.md` when a stage is done.
4. Prefer conventional commit messages if you commit:
   - `feat(stage-01): complete products API practice`
   - `docs: mark stage 00 complete`
5. Never commit `.env` or secrets.
